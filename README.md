# Personal Finance Tracker

A full-stack personal finance tracking application built with Node.js, Express, Supabase, React, and Material UI.

## Features

- Add daily expenses with amount, category, description, and date
- View totals for today, this week, and this month
- Set a daily spending limit and get warnings when it is exceeded
- Track bank balance with automatic subtraction when expenses are added
- Dashboard with summary cards, recent transactions, and charts
- Responsive UI and persistent Supabase storage

## Project Structure

- `backend/` - Express + Supabase API
- `frontend/` - React + Vite dashboard

## Setup

### 1. Install dependencies

```bash
npm install
npm install --workspace backend
npm install --workspace frontend
```

### 2. Configure environment variables

Create `backend/.env` from `backend/.env.example` and set your Supabase project URL and service role key.

Create `frontend/.env` from `frontend/.env.example` and set the API base URL plus the Supabase public client variables.

### 3. Run the app

Start both apps from the root:

```bash
npm run dev
```

Or run individually:

```bash
npm run dev:backend
npm run dev:frontend
```

### 4. Seed sample data

```bash
npm run seed
```

### 3a. Create the Supabase tables

Run this SQL in the Supabase SQL editor:

```sql
create table if not exists public.settings (
	id bigint primary key,
	daily_limit numeric not null default 0,
	balance numeric not null default 0,
	created_at timestamptz not null default now(),
	updated_at timestamptz not null default now()
);

create table if not exists public.expenses (
	id bigint generated by default as identity primary key,
	amount numeric not null,
	category text not null,
	description text not null default '',
	date date not null,
	created_at timestamptz not null default now(),
	updated_at timestamptz not null default now()
);

insert into public.settings (id, daily_limit, balance)
values (1, 0, 0)
on conflict (id) do nothing;
```

## API Endpoints

- `POST /api/expenses` - add an expense
- `GET /api/expenses?period=day|week|month` - list expenses with filters
- `GET /api/summary` - get dashboard totals and remaining balance
- `POST /api/limit` - set daily limit and optional balance

## Notes

- Supabase is required for persistence.
- Authentication is not enabled in this single-user version, but the structure can be extended with JWT later.
